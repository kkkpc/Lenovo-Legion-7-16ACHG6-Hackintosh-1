### 🔄 Installation Steps
1. **Download OpenCore EFI**: Click on the download link above to access the Releases page. Select the latest version of the EFI folder.
2. **Extract the File**: After downloading, locate the downloaded file on your computer and extract it.
3. **Create a macOS USB Installer**:
   - Use a USB drive with at least 16GB of space.
   - Follow guide instructions for creating a bootable macOS USB installer. Look up tools like UniBeast for assistance.
4. **Copy EFI Folder**: 
   - Open the extracted EFI folder.
   - Drag and drop it into the EFI partition of your USB drive.
5. **Boot from USB**: 
   - Restart your laptop and enter the boot menu (usually by pressing F12 or F2 during startup).
   - Select the USB drive to start the macOS installation.
6. **Follow macOS Installation Prompts**: 
   - Choose the desired macOS version.
   - Continue with on-screen instructions.
